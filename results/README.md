# Results

## Overview

This folder contains the experimental results, model evaluations, visualizations, and findings from the **Predicting the Severity of AI and LLM Vulnerabilities** project.

**Project:** AAI-501 Final Project – Team 2  
**University:** University of San Diego

## Purpose

The `results/` folder serves as a central location for consolidating and comparing findings from all team members' analyses.

Results will support the final project report and presentation.

## Results Organization

This folder may include:

- **Model Performance:** Evaluation metrics for Logistic Regression, Random Forest, and other experimental models.
- **Model Comparisons:** Comparative results across different algorithms and feature sets.
- **Visualizations:** Confusion matrices, ROC curves, feature distributions, and other analytical charts.
- **Clustering Results:** Patterns and groupings identified through unsupervised learning.
- **Key Findings:** Summaries of observations, model performance, and limitations.

## Evaluation Metrics

Models will be evaluated using:

- Accuracy
- Precision
- Recall
- Macro F1-score
- ROC curves
- Recall for critical vulnerabilities

**Primary evaluation priorities:** Macro F1-score and critical vulnerability recall, reflecting the importance of identifying high-risk vulnerabilities while accounting for class imbalance.

## Collaboration Guidelines

- Store finalized results intended for team comparison in this folder.
- Include descriptive filenames identifying the experiment or model.
- Document the dataset version, features, model parameters, and evaluation approach.
- Use the team's agreed-upon time-based train/test split for valid comparisons.
- Clearly distinguish experimental results from final validated findings.
- Avoid committing temporary files, duplicate outputs, or large intermediate datasets.
