# Project Presentation

## Overview

This folder contains the final presentation materials for **Predicting the Severity of AI and LLM Vulnerabilities**.

The presentation will summarize the research objectives, methodology, machine learning experiments, results, and conclusions.

## Presentation Content

The presentation is expected to cover:

1. **Problem and Motivation:** Why predicting AI vulnerability severity matters.
2. **Dataset Overview:** AI Sec Watch Dataset and relevant features.
3. **Data Preparation:** Cleaning, preprocessing, and leakage prevention.
4. **Machine Learning Approaches:** Logistic Regression, Random Forest, and supporting analyses.
5. **Model Evaluation:** Accuracy, precision, recall, Macro F1-score, and critical vulnerability recall.
6. **Results and Comparisons:** Key visualizations and model performance.
7. **Conclusions:** Findings, limitations, and potential applications.
