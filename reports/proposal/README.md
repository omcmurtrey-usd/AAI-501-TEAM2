# Project Proposal

## Overview

This folder contains the original project proposal for **Predicting the Severity of AI and LLM Vulnerabilities**.

The proposal establishes the research problem, objectives, machine learning methodology, evaluation criteria, and expected outcomes.

## Research Objective

Develop machine learning models to predict AI software vulnerability severity using written descriptions and relevant metadata.

The classification task includes four severity levels:

- Low
- Medium
- High
- Critical

## Proposed Methodology

- **Dataset:** AI Sec Watch Dataset v4.0.
- **Baseline Model:** Logistic Regression.
- **Comparative Model:** Random Forest.
- **Supporting Analysis:** Clustering to explore vulnerability patterns.
- **Optional Extension:** Neural Network.

The project will use a time-based train/test split and evaluate performance using accuracy, precision, recall, F1-score, and ROC curves.

Primary evaluation priorities are **Macro F1-score** and **critical vulnerability recall**.
