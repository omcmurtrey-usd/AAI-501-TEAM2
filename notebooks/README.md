# Notebooks

This folder contains individual Jupyter notebooks developed by Team 2 for the **Predicting the Severity of AI and LLM Vulnerabilities** project.

## Folder Structure

- **`olena/`** — Olena's analysis, experiments, and results.
- **`kate/`** — Kate's analysis, experiments, and results.
- **`aren/`** — Aren's analysis, experiments, and results.

## Purpose

Each team member maintains their own workspace to independently explore the dataset, develop machine learning models, and evaluate results.

The project focuses on predicting vulnerability severity using classification techniques, supported by exploratory analysis and clustering.

## Collaboration Guidelines

- **Independent work:** Keep individual notebooks within the assigned team member's folder.
- **Consistency:** Follow agreed-upon preprocessing, feature selection
