# Processed Data

This folder contains cleaned versions of the **AI Sec Watch Dataset v4.0**, contributed by Team 2 members for comparison and review.

## Purpose

Compare individual data cleaning approaches and select a consistent, finalized dataset for machine learning experiments.

## Guidelines

- Each team member should store their cleaned dataset in a folder identified by their name.
- Include a short README documenting cleaning decisions and transformations.
- Preserve the original dataset in `data/raw/`.
- Review differences in data quality, retained features, missing values, and potential data leakage.
- Agree on one finalized dataset for shared model training and evaluation.

## Folder Structure

- `olena-cleaned-data/` — Olena's cleaned dataset.
- `kate-cleaned-data/` — Kate's cleaned dataset.
- `aren-cleaned-data/` — Aren's cleaned dataset.
- `final/` — Team-approved cleaned dataset.
