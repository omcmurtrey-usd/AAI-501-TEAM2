# Finalized Cleaned Data

This folder contains the finalized, cleaned dataset for the **Predicting the Severity of AI and LLM Vulnerabilities** project.

## Purpose

Provide a consistent, shared dataset for all team members to use in machine learning experiments and model comparisons.

## Data Preparation

The dataset has undergone cleaning and preprocessing, including:

- Review of missing values and data quality.
- Review of features relevant to vulnerability severity prediction.
- Identification of potential data leakage from severity-related fields.
- Preparation of data for further analysis and modeling.

## Usage Guidelines

- **Shared dataset:** All team members should use the same approved version.
- **Data integrity:** Keep the finalized cleaned dataset unchanged.
- **Reproducibility:** Document any additional transformations in individual notebooks.
- **Consistency:** Use agreed-upon features, severity labels, and evaluation procedures.

## Related Folders

- `../raw/` — Original, unmodified dataset.
- `../../notebooks/` — Individual analyses and experiments.
- `../../results/` — Model evaluations and findings.
